STEP-BY-STEP PLAY

  1. Click ▶ PLAY in the header
  2. Optional: upload your own image via the Upload zone in the Puzzle Board panel
  3. Allow camera access when prompted
  4. Wait for the green "HAND DETECTED" status
  5. Select grid size manually (3×3, 4×4, or 5×5) or use two-hand pinch-spread to dynamically resize the grid
  6. Click START GAME or show OPEN PALM
  7. Use PINCH (thumb + index finger) to grab a puzzle piece
  8. Move your hand to drag the piece
  9. Release (open fingers) to drop the piece
  10. Piece snaps if near the correct position
  11. Complete all pieces to win 🎉

AI TECHNOLOGY
MediaPipe Hand Landmarker
Google's MediaPipe detects 21 3D hand landmarks in real time. Each landmark provides normalised x, y, z coordinates within the image frame. Runs at 30+ FPS on standard hardware.
ML ALGORITHM
Random Forest Classifier
200 decision trees trained on 78-dimensional feature vectors derived from hand landmarks. Uses majority voting with probability outputs for confidence estimation. Trained with scikit-learn.
INPUT FEATURES
78 Hand Landmark Features
63 normalised (x,y,z) coordinates from 21 landmarks — relative to the wrist and scaled by bounding box diagonal — plus 15 inter-fingertip Euclidean distance features.
OUTPUT CLASSES
6 Gesture Categories
PINCH · OPEN_PALM · FIST · THUMBS_UP · ONE_FINGER · TWO_FINGERS. Each prediction includes a per-class probability vector enabling real-time confidence display.
BACKEND API
FastAPI + WebSocket
Python FastAPI server exposes REST and WebSocket endpoints. The frontend sends 78-element feature vectors; the backend returns gesture predictions within milliseconds.
ADAPTIVE AI
Performance Analysis Engine
After each completed game the system calculates a composite performance score from time, moves, mistakes, and gesture accuracy — then recommends the appropriate difficulty level.

WHY RANDOM FOREST?

Ensemble Learning 200 decision trees vote on the gesture. Majority vote reduces overfitting and increases robustness to noisy or slightly misaligned hand positions.
Feature Importance RF automatically ranks which of the 78 features matter most — typically inter-fingertip distances and wrist-relative tip positions.
Probability Outputs predict_proba() returns confidence per class, enabling the real-time confidence bar shown in the UI — not a fake score.
Fast Inference Random Forest inference is O(depth × trees) — microsecond latency per frame suitable for real-time gesture recognition.
